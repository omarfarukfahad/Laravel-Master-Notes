# 📚 Laravel Master Notes

A modern, responsive learning resource for Laravel developers. Laravel Master Notes is designed to help developers learn Laravel concepts, explore code examples, and quickly reference common commands and project structures.

🌐 **Live Website:** https://omarfarukfahad.github.io/Laravel-Master-Notes/

📦 **GitHub Repository:** https://github.com/omarfarukfahad/Laravel-Master-Notes

## ✨ Features

- 📖 Laravel learning notes and quick references

## 🚀 Getting Started

### Prerequisites

Install the following tools before starting:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/omarfarukfahad/Laravel-Master-Notes.git
```

### 2. Open the Project Folder

```bash
cd Laravel-Master-Notes
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

### 5. Build for Production

```bash
npm run build
```

The production-ready files will be generated in the `dist/` directory.

### 6. Preview the Production Build

```bash
npm run preview
```

## 🌍 Deployment

This project can be deployed as a static website using GitHub Pages or compatible static hosting services.

For GitHub Pages project deployment, configure the Vite base path in `vite.config.ts`:

```typescript
base: '/Laravel-Master-Notes/',
```

Then build the project:

```bash
npm run build
```

Publish the contents of the generated `dist/` directory according to your hosting provider's deployment instructions.
